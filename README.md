# 食品过敏原标签审查台

基于 **Python + FastAPI + SQLite** 的 Web 工具：录入带嵌套子配料的配方文本与标签过敏原声明，
自动解析括号层级、向上传播每个原料的过敏原集合，核对标签的**漏标 / 多报**，支持两版配方对比并导出审查报告。

## 功能

- **嵌套配料解析**：支持全角/半角括号 `（）()`、`【】` 多层嵌套，逗号 `,，`、顿号 `、`、分号 `;；` 分隔。
  复合原料（如 `坚果酱（扁桃仁、腰果）`）的子配料过敏原会传播到父级与顶层。
- **过敏原传播**：每个节点的过敏原 = 自身命中 ∪ 全部后代命中；页面以「直接命中 / 子配料传播 ▲」两种徽章区分。
- **标签核对**：
  - **漏标**：配方含但标签未声明；
  - **多报**：标签声明但配方不含；
  - **未识别**：声明片段无法对应到字典类别（单独提示）。
- **两版对比**：粘贴两版文本或选择两个已存版本，输出过敏原类别增减、叶子原料增减、按类别的来源变化。
- **字典维护**：预置 GB 7718-2025 致敏物标识相关 8 类（麸质谷物、甲壳类动物、鱼类、蛋类、花生、大豆、乳、坚果）及 60+ 常见原料，可在页面增删改、新增类别与别名。
- **报告导出**：单版 / 对比均可导出 Markdown 或 TXT 审查报告。
- SQLite 持久化，零外部依赖；另提供 JSON API。

## 一键启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后访问：

- 审查台首页：<http://localhost:8000/>
- 端口：**8000**
- 数据文件：容器内 `/data/allergen.db`，保存在 Docker 卷 `allergen-data` 中

停止：

```bash
docker compose down          # 保留数据
docker compose down -v       # 同时删除数据卷
```

## 本地直接运行（可选）

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

数据库路径可用环境变量 `ALLERGEN_DB` 覆盖（默认 `/data/allergen.db`，本地运行可设为 `./allergen.db`）。

## 使用示例

**配方文本**

```
小麦粉、水、坚果酱（扁桃仁、腰果、白砂糖）、全脂乳粉、大豆磷脂、鸡蛋、酵母、食用盐
```

**标签声明**

```
本产品含有：麸质谷物、乳、蛋
```

审查结果：检出 5 类（麸质谷物、坚果、乳、大豆、蛋类），标签**漏标：坚果、大豆**。

**两版对比示例**

- 旧版：`小麦粉、水、全脂乳粉、鸡蛋、酵母、食用盐`
- 新版：`小麦粉、水、坚果酱（扁桃仁、腰果）、全脂乳粉、鸡蛋、酵母、食用盐`

对比输出：新增过敏原 **坚果**，新增原料 **扁桃仁、坚果酱、腰果**（坚果酱为复合原料）。

## 解析与匹配规则

- 括号不配对会给出错误提示；未命名括号组的子项自动提升。
- 原料名匹配字典：**精确匹配优先**，否则取最长子串键（键长度 ≥ 2，避免单字误命中）。
  复合原料自身命中与子配料传播取并集。
- 标签声明按标点切分后，按类别「名称 + 别名」识别，支持片段包含匹配（如「含乳制品」→ 乳）。
- 精炼大豆油等默认不映射过敏原的原料已预置为「无」，可在字典页按实际情况调整。

## JSON API

```bash
curl "http://localhost:8000/api/review?ingredients=小麦粉、牛奶、花生&declared=含有乳"
```

```json
{
  "detected_allergens": ["乳", "花生", "麸质谷物"],
  "missing": ["花生", "麸质谷物"],
  "extra": [],
  "unrecognized_declared": [],
  "label_ok": false,
  "leaves": { "乳": ["牛奶"], "花生": ["花生"], "麸质谷物": ["小麦粉"] }
}
```

健康检查：`GET /healthz`。

## 页面路径

| 路径 | 说明 |
| --- | --- |
| `/` | 单版配方审查（可勾选保存） |
| `/compare` | 两版配方过敏原对比 |
| `/recipes` | 已存配方版本管理与报告下载 |
| `/dict` | 过敏原类别与原料字典维护 |

> 本工具用于标签合规的辅助审查，字典默认值不构成合规结论；正式标识请结合原料供应商规格与适用法规判断。
